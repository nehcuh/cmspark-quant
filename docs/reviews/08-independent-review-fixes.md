# 08 Independent review (#5–#11): reproduction, fix, adversarial re-review (2026-10-21)

Baseline `2de65f5`. Each reviewer diagnostic was first reproduced on the
baseline, then turned into a regression in `crates/cmsq-core/tests/independent_audit.rs`,
which asserts the safe behaviour and FAILS on the baseline logic (verified by
temporarily restoring the old code path).
